# utility-ts

A TypeScript utility library.

## Installation

```bash
npm install utility-ts
```

## Usage

```typescript
import { exampleUtil } from 'utility-ts';

const result = exampleUtil('hello');
console.log(result); // 'HELLO'
```

## Development

### Prerequisites

- Node.js >= 14.0.0
- npm

### Setup

```bash
npm install
```

### Build

```bash
npm run build
```

### Watch Mode

```bash
npm run build:watch
```

### Clean

```bash
npm run clean
```
